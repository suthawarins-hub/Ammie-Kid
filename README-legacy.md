# Pregnant Manager Pro — Soft Pastel Edition

เว็บแอปสมุดบันทึกครอบครัวสำหรับมือถือ (GitHub Pages + Supabase)

## ธีมพาสเทล

- Ballet Pink · `#FBE7EE` — โปรไฟล์คุณแม่และการบันทึกความทรงจำ
- Lavender · `#EFEBFF` — แท็บ ปุ่มรอง และภาพประกอบ
- Seafoam Mint · `#E8F5ED` — ความคืบหน้าและเช็กลิสต์
- Cloud Blue · `#E7F2FE` — โปรไฟล์คุณพ่อ
- Warm Ivory · `#FFFCFA` — พื้นผิวหลัก
- Dusty Sage · `#557970` — ปุ่มสำคัญและองค์ประกอบที่ต้องมีความเปรียบต่างเพื่ออ่านง่าย

แก้ไขสีในไฟล์ `theme-pastel.css` ที่ตัวแปร `:root` ได้โดยไม่ต้องแตะฐานข้อมูลหรือ JavaScript

## ติดตั้ง

1. สร้างโปรเจ็กต์ Supabase ของครอบครัว และตั้งค่า Supabase Auth (Email), รวมถึงยืนยันอีเมลตามที่ต้องการ
2. เปิด SQL Editor แล้วตรวจสอบและเรียกใช้ `supabase.sql` ในโปรเจ็กต์ของคุณ
3. ใส่ Supabase Project URL และ **publishable/anon key** ใน `config.js` (ห้ามใส่ `service_role` หรือ secret key ในเว็บ)
4. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดไว้ในตำแหน่งเดียวกันบน GitHub repository แล้วเปิด GitHub Pages
5. เปิดผ่าน HTTPS สมัครบัญชี และทดสอบการบันทึกข้อมูล/รูปภาพกับสองบัญชีที่ได้รับสิทธิ์ก่อนใช้ข้อมูลจริง
6. เมื่อติดตั้งบนหน้าจอโฮมของมือถือแล้ว ให้เปิดใหม่หลังเปลี่ยนเวอร์ชันหากพบว่า CSS ยังไม่อัปเดต

**สำคัญ:** ไม่ควรบันทึกข้อมูลสุขภาพจริงจนกว่าจะทดสอบ Row Level Security, Storage permissions, การเชิญสมาชิก และการสำรองข้อมูลครบถ้วน

## ไฟล์สำคัญ

- `index.html` หน้าตาและโครง UI
- `theme-pastel.css` ธีมสีพาสเทลใหม่
- `app.js` ฟังก์ชันระบบเดิม (การตั้งครรภ์ อาการ นัดหมาย PIN ลูกดิ้น ฯลฯ)
- `config.js` การตั้งค่า Supabase
- `supabase.sql` ตารางและนโยบายฐานข้อมูล
- `manifest.webmanifest`, `sw.js`, `assets/icon.svg` การแสดงผลเมื่อเพิ่มเว็บลงหน้าจอมือถือ

## ข้อจำกัดของโหมดทดลอง

หากยังไม่ใส่ Supabase URL และ key ระบบจะเปิดให้ลอง UI เท่านั้น โดยข้อมูลในโหมดทดลองไม่ถูกจัดเก็บถาวร

PIN เป็นล็อกเฉพาะอุปกรณ์ ไม่ใช่การแยกสิทธิ์ของคุณพ่อกับคุณแม่ใน Supabase ทั้งสองโปรไฟล์เห็นข้อมูลร่วมกัน

ระบบนี้ช่วยจดบันทึก ไม่ใช่อุปกรณ์แพทย์และไม่ได้ประเมินความปลอดภัยหรือวินิจฉัยโรค


## 📱 ติดตั้งเป็นแอปบนมือถือ (PWA Edition)

ไฟล์ชุดนี้ได้รับการปรับปรุงให้ติดตั้งจากหน้า GitHub Pages แบบ **PWA** ได้ พร้อมไอคอนพาสเทลขนาด 192 × 192, 512 × 512, maskable 512 × 512 และ Apple touch icon

1. อัปโหลดไฟล์และโฟลเดอร์ใน ZIP ทั้งหมด (รวม `assets`, `manifest.webmanifest`, `sw.js`, `install-pwa.js`, `install-pwa.css`) ไปที่ GitHub repository ที่เปิด Pages
2. รอ GitHub Pages เผยแพร่หน้าเว็บไซต์ด้วย HTTPS แล้วเปิดลิงก์ด้วยมือถือ
3. **Android / Chrome**: กดแถบ “ติดตั้ง” ในแอป หรือเมนู Chrome ⋮ > Install app / Add to Home Screen
4. **iPhone**: เปิดผ่าน Safari กด Share > Add to Home Screen > Open as Web App (ถ้ามี) > Add
5. ไอคอนแอปจะปรากฏบนหน้าจอ และเปิดแบบเต็มหน้าจอได้

**นี่คือเว็บแอป PWA ไม่ใช่ APK/IPA** จึงยังไม่ได้ลง Google Play หรือ App Store; การติดตั้งต้องทำจากลิงก์ HTTPS ของเว็บที่เผยแพร่แล้ว ไม่ใช่ไฟล์ ZIP ที่เปิดตรงในมือถือ

**ความเป็นส่วนตัว:** Service worker แคชเฉพาะไฟล์โครงเว็บ (HTML, CSS, JS, ไอคอน) ไม่แคชภาพครอบครัว, ข้อมูลสุขภาพ, คำตอบจาก Supabase หรือ API ภายนอก การเปิดแบบออฟไลน์ไม่ได้รับประกันว่าจะเข้าใช้ข้อมูลได้ และ **การบันทึกกับซิงก์ต้องมีอินเทอร์เน็ต**. โปรดตั้งค่า Supabase Auth และทดสอบ RLS/Storage ให้สำเร็จก่อนใช้ข้อมูลจริง


## ตั้งค่า Supabase สำหรับโปรเจกต์นี้ (27 October 2026)

ไฟล์ `config.js` ใส่ Project URL และ **publishable key** ที่เจ้าของโปรเจกต์ส่งมาแล้ว
จึงไม่จำเป็นต้องแก้สองค่านี้อีก เว้นแต่เปลี่ยนโปรเจกต์หรือหมุนเวียนคีย์

**ยังไม่ได้สร้างตารางบน Supabase ให้โดยอัตโนมัติ**: เข้า Supabase SQL Editor ของโปรเจกต์นี้ ตรวจสอบ SQL แล้วรัน `supabase.sql` หนึ่งครั้งบนโปรเจกต์ที่ยังไม่มีตาราง/นโยบายซ้ำ
เปิด Authentication > Providers > Email; ควรใช้ Email confirmation สำหรับบัญชีครอบครัว
เปิด Authentication > URL Configuration และตั้ง Site URL / Redirect URLs เป็น URL GitHub Pages จริงที่จะใช้งาน

อัปโหลดทุกไฟล์ใน ZIP ไปยัง root ของ GitHub repository (ไม่ใช่เอา ZIP ไปวางเป็นไฟล์เดียว)
เปิด GitHub Pages ผ่าน HTTPS, สมัคร/เข้าสู่ระบบ, สร้างครอบครัว และทดลองเชิญอีกบัญชี
ทดสอบให้บัญชีที่ไม่ได้รับเชิญไม่สามารถอ่าน/ดาวน์โหลดข้อมูลหรือภาพได้ก่อนนำข้อมูลสุขภาพจริงเข้าใช้งาน

คีย์ `sb_publishable_...` เป็นคีย์สำหรับเว็บฝั่งผู้ใช้ **ไม่ใช่** รหัสผ่านของฐานข้อมูล
การระบุ URL+คีย์ในไฟล์ไม่ได้ยืนยันว่าเชื่อมต่อสำเร็จ และไม่ได้สร้างตารางให้

## Pastel Atelier v5 — ดีไซน์ใหม่ทั้งระบบ

เวอร์ชันนี้อัปเกรดการจัดวางและสไตล์ของ Dashboard, สุขภาพ, Checklist,
Gallery, หน้า Settings, หน้าล็อกอิน/PIN และฟอร์มบันทึกข้อมูล โดยเพิ่ม `premium-ui.css`
ที่โหลดหลัง `theme-pastel.css` และจัดโครงหน้า Settings ใหม่ใน `app.js`.

- **สิ่งที่ไม่เปลี่ยน:** `config.js`, Schema และ RLS ใน `supabase.sql`, ตารางข้อมูลเดิม,
  ระบบสมาชิกและ PIN, Action ของฟอร์มบันทึกทั้งหมด
- **หากเคยรัน SQL แล้ว:** ไม่จำเป็นต้องรันอีกเพื่อปรับ UI
- **การอัปเดตเว็บเดิม:** อัปโหลดไฟล์ทั้งหมดทับไฟล์เว็บไซต์เก่า โดยเฉพาะ
  `index.html`, `app.js`, `premium-ui.css`, `sw.js` จากนั้นปิดและเปิดแอปใหม่
- **PWA Cache:** ยกเวอร์ชัน Service Worker เป็น v5 และเพิ่ม `premium-ui.css`
- **ข้อจำกัดในการทดสอบ:** มีการทดสอบอินเทอร์เฟซด้วยเบราว์เซอร์จำลองโดยใช้
  โหมดทดลอง ไม่ได้ทดสอบการเชื่อม Supabase จริงหรือติดตั้งบนเครื่องมือถือจริง
