Pregnant Manager Pro - SQL Setup

1. Supabase Dashboard > Your project > SQL Editor > New query.
2. Copy all content from supabase.sql > Run.
3. Authentication > Providers > Email: enable email confirmation.
4. Authentication > URL Configuration: allow exact GitHub Pages URL.
5. Upload entire web app folder contents to GitHub Pages (not ZIP).
6. First account creates household. Second account registers AND confirms email.
7. First account invites second user's email. Second user signs in, accepts automatically.
8. Test data upload, charts, appointments, photos, and forbidden third-account access.

Note: website PIN is device-only. PostgreSQL stores family data; it does not send push notifications or diagnose medical conditions.
