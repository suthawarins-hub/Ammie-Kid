# Pregnant Manager Pro v7.2 — Remember My Parent Profile

## เปลี่ยนอะไร
- ครั้งแรกที่ไม่มีโปรไฟล์ที่เคยปลดล็อก จะให้เลือก **คุณพ่ออาร์** หรือ **คุณแม่เอมมี่** แล้วตั้ง/กรอก PIN
- หลังปลดล็อกสำเร็จ ระบบเก็บเฉพาะ **ชื่อโหมดที่ใช้ล่าสุด** ตามบัญชี Supabase บนอุปกรณ์นี้ (`pmp-role-<user id>`)
- เมื่อเปิดแอปอีกครั้ง ขณะเซสชัน Supabase ยังใช้ได้ หน้าจอ PIN จะแสดง **รูปการ์ตูนโปรไฟล์ล่าสุดเพียงคนเดียว** เช่น เลือกพ่อ = เห็นพ่ออย่างเดียว ไม่แสดงปุ่มคุณแม่
- การสลับไปใช้อีกโหมดต้องเข้าไปที่ **ตั้งค่า > เปลี่ยนโหมด** แล้วกดยืนยันและกรอก PIN ของโหมดใหม่ หลังปลดล็อกสำเร็จจึงจำโหมดใหม่
- ไม่ต้องรัน SQL ใหม่ ยังคง Supabase, ข้อมูลครอบครัว, v7 checklist, Pink Book และ PWA เดิม

## ติดตั้ง
1. สำรองไฟล์เดิมก่อน และอัปโหลดไฟล์เว็บ v7.2 ทั้งชุดแทนของเดิมบน GitHub Pages (ไฟล์หลัก app.js, access-v7.1.css, index.html, sw.js)
2. เปิดแอปออนไลน์หนึ่งครั้งเพื่อให้ service worker อัปเดต ถ้าหน้าจอเก่ายังค้างให้รีเฟรชเว็บหรือเปิดปิด PWA อีกครั้ง
3. เปิดด้วยบัญชีเดิม เลือกคุณพ่อ กรอก PIN ถูกต้อง / ตั้ง PIN หากยังไม่เคยมี แล้วล็อกแอปและเปิดซ้ำ จะเห็นเพียงโปรไฟล์คุณพ่อ

## ความปลอดภัย
PIN ของระบบนี้เป็นตัวล็อกหน้าจอฝั่งอุปกรณ์เท่านั้น ไม่ใช่การยืนยันตัวตนแทน Supabase Auth ถ้าเซสชันหมดอายุ ต้องเข้าสู่ระบบด้วย Passkey หรืออีเมลก่อน โปรไฟล์สองโหมดอาจแชร์บัญชี Supabase เดียวกัน หากต้องการแยกสิทธิ์ผู้ใช้อย่างแท้จริงให้ใช้บัญชี Supabase แยกกันและ RLS

## ทดสอบ
ไฟล์ app.js ผ่าน node --check และทดสอบเส้นทาง UI ด้วยเบราว์เซอร์จำลอง; ยังไม่ได้เชื่อมเข้าบัญชีจริงของผู้ใช้
