# Pregnant Manager Pro v7 — Pastel Atelier (GitHub Pages + Supabase)

## อัปเดตฟีเจอร์

1. Smart Pregnancy Timeline: คำนวณสัปดาห์และเดือนโดยประมาณจากกำหนดคลอดที่บันทึก
2. Digital Pink Book: บันทึกผลฝากครรภ์ที่แพทย์แจ้ง ความดัน น้ำหนัก สถานที่ และโน้ต พร้อมพิมพ์ / Save as PDF
3. Health Insights: กราฟข้อมูลจริงที่กรอกเอง (น้ำหนัก ความดัน อารมณ์ การเติบโตของลูก) + Python analysis script แบบออฟไลน์
4. Family Reminders: นัดแพทย์ในระบบเดิม + บันทึกการเตือน + export .ics เพื่อเพิ่มลงปฏิทิน
5. Baby Shopping Planner: รายการหมวดหมู่, จำนวน, งบประมาณ, ค่าใช้จ่ายจริง และการปรับรายการ
6. Family Memory Book: ภาพครอบครัว, อัลตราซาวด์, ภาพคุณแม่รายเดือน, ข้อความ/จดหมายถึงลูก
7. Newborn Care: นม / การนอน / ผ้าอ้อม / น้ำหนัก / ส่วนยาว / บันทึกแม่หลังคลอด
8. Vaccines & Development: บันทึกวัคซีนจากสมุด/ใบนัดจริง, กิจกรรมพัฒนาการ, *ไม่คาดเดาตารางวัคซีน*
9. Family Collaboration: บันทึกของครอบครัวร่วมกันและรายการกิจกรรมล่าสุด, เชิญด้วยบัญชี Supabase ที่ได้รับสิทธิ์
10. Private Vault: PIN 6 หลัก, lock screen, auto-lock, RLS Supabase, Private Storage, ส่งออก JSON, พิมพ์ข้อมูล
11. **9 Months of Mommy:** ภาพคุณแม่ตั้งครรภ์เดือน 1–9 ระบุวัน สัปดาห์ และข้อความถึงลูก ดูภาพเต็มภายหลังได้

## เข้าแอปด้วย PIN — ไม่ต้องกรอกอีเมลทุกครั้ง

- **ครั้งแรกของแต่ละอุปกรณ์**: ลงชื่อเข้าใช้ด้วย Supabase Email/Password ตามปกติ แล้วเลือกคุณแม่หรือคุณพ่อเพื่อตั้ง PIN 6 หลัก
- **ครั้งต่อไป**: หากเซสชัน Supabase ยังอยู่และใช้ได้ ให้เลือกโปรไฟล์ กรอก PIN แล้วเข้าทันที
- PIN ของแต่ละโปรไฟล์แยกกันภายใน **บัญชี Supabase ที่กำลังล็อกอินบนอุปกรณ์นั้น**; PIN ไม่ได้เปลี่ยนสิทธิ์ฐานข้อมูล
- หากลืม PIN กด “ลืม PIN? เข้าสู่ระบบด้วยอีเมลใหม่” แล้วยืนยันการลงชื่อเข้าใช้ใหม่
- เมื่อเซสชันหมดอายุ ถูกเพิกถอน ออกจากระบบ หรือถูกล้าง browser data จะต้องลงชื่อเข้าใช้ด้วยอีเมลใหม่ ไม่สามารถให้ PIN ข้ามขั้นตอนนี้ได้
- มี auto-lock เมื่ออยู่พื้นหลังเกิน 5 นาที หรือไม่ทำกิจกรรมในแอปเกิน 20 นาที
- ระเบียน PIN ใหม่ใช้ PBKDF2 SHA-256 (150,000 รอบ) พร้อม salt เฉพาะอุปกรณ์ ส่วน PIN รุ่นเก่าที่เข้าได้จะอัปเกรดอัตโนมัติ

## ติดตั้งบนฐานข้อมูลเดิม

1. **ก่อนอัปเกรด:** สำรองข้อมูลเดิมโดยใช้เมนู JSON (หากระบบเดิมใช้งานได้) และยืนยันสถานะ RLS/Storage
2. **ถ้าเคยรัน supabase.sql v2 แล้ว:** ให้รัน `v7_upgrade.sql` ใน Supabase SQL Editor เพียงไฟล์เดียว เพื่ออนุญาต collection ใหม่ `prenatalVisits` และ `reminders` โดยไม่ลบข้อมูลเดิม
3. **ถ้ายังไม่มีฐานข้อมูล:** รัน `supabase.sql` ฉบับเต็ม (ไม่ต้องรัน v7_upgrade ซ้ำ)
4. อัปโหลด **ไฟล์ข้างใน ZIP ทั้งหมด** รวม `v7-ui.css`, `app.js`, `index.html`, `sw.js` และ `assets/` ไปยัง GitHub Pages ของเดิม
5. เปิดเว็บบนมือถือในโหมดออนไลน์ แล้วทดสอบล็อกอินครั้งแรก ตั้ง PIN ปิดแอป เปิดใหม่ และตรวจการบันทึก/อ่านข้อมูลกับ Supabase จริง
6. หาก PWA ยังเห็นหน้าเก่า ให้รีเฟรชหรือติดตั้งใหม่หลังตรวจ Service Worker v7 ว่าอัปเดตแล้ว

**ห้ามนำ service_role / sb_secret key ไปใส่ `config.js`**: ใช้เฉพาะ publishable key ตามเดิม และเปิด RLS/Storage policies จริง

## ความปลอดภัยทางการแพทย์

- กราฟวิเคราะห์เชิงพรรณนาเท่านั้น ไม่ใช้ AI ประเมินความเสี่ยงหรือทำนายภาวะสุขภาพ
- ระบบนับลูกดิ้นไม่ได้กำหนดเกณฑ์ที่ใช้ตัดสินความปลอดภัย หากดิ้นน้อยลงหรือเปลี่ยนแปลงจากปกติ ให้ติดต่อสถานพยาบาลทันที
- ตารางวัคซีนไม่สร้างอัตโนมัติ ต้องคัดลอกวันนัดจากสมุดสุขภาพเด็ก/เจ้าหน้าที่สาธารณสุข
- การแจ้งเตือนภายในแอป **ไม่ใช่การส่ง Push notification ขณะปิดแอป**; สามารถส่งกำหนดการไปปฏิทินด้วย .ics หรือ Google Calendar ในส่วนที่รองรับ
- รูปภาพถูกเก็บแบบ Private ใน Supabase Storage; ข้อมูลส่งออก JSON **ไม่รวมไบนารีรูปต้นฉบับ**
- แอปยังไม่ใช่อุปกรณ์แพทย์ ไม่ใช้แทนสมุดสีชมพูหรือการประเมินโดยแพทย์

## Python สำหรับสรุปข้อมูลส่วนตัว (ไม่ต้องใช้เซิร์ฟเวอร์)

หลังดาวน์โหลด JSON จากแอป:

```bash
python tools/analyze_export.py pregnant-manager-pro-backup-2026-10-27.json
```

จะสร้าง CSV สำหรับกราฟและสถิติ `count`, `first`, `last`, `change`, `average` โดยไม่ส่งข้อมูลออกอินเทอร์เน็ตและไม่ตีความเกณฑ์ทางคลินิก เว็บ PWA บน GitHub Pages ทำงานด้วย JavaScript ไม่สามารถรัน Python บน GitHub Pages โดยตรงได้
