# Pregnant Manager Pro v7.3 — Baby Name Auto

## ใช้งาน
1. ติดตั้งเว็บเวอร์ชันนี้ลง GitHub Pages เดิม อัปโหลดไฟล์ใน ZIP ทั้งหมดไว้ที่ root ของไซต์ (ไม่ใช่โฟลเดอร์ชั้นใน)
2. เปิด **Settings → ชื่อของเจ้าตัวเล็ก → เลือกเพศลูกจากผลตรวจ**
3. เลือก **ยังไม่ทราบ / ลูกสาว / ลูกชาย** และยืนยันการเลือกก่อนบันทึก
4. ระบบจะใช้ชื่อเล่นภาษาไทยและอังกฤษตามการเลือกบน Dashboard, Timeline, อัลบั้ม Mommy, สมุดความทรงจำ, หน้าหลังคลอด และหน้าสรุป PDF
5. ชื่อสามารถแก้ไขที่ปุ่ม **แก้ไขชื่อและข้อมูลลูก** (แก้ชื่อเล่นไทย–อังกฤษได้) โดยระบบจะใช้ชื่อใหม่ทันทีหลังบันทึก

## ข้อมูลที่เก็บ
ใช้ field `settings.gender` ใน JSONB ของครอบครัวเดิม (`unknown`, `female`, `male`) ผ่าน `pmp_merge_settings`. ไม่ต้องรัน SQL ใหม่ถ้าระบบ v7.2 เดิมสามารถบันทึกข้อมูลครอบครัวได้อยู่แล้ว. การเลือกเพศเป็นข้อมูลที่ผู้ใช้กรอกเอง ไม่ใช่ผลการตีความ NIPT หรือการวินิจฉัยของแอป

## ทดสอบและข้อจำกัด
การเปลี่ยนเพศปรับข้อความ UI เท่านั้น ไม่ลบหรือแก้บันทึกย้อนหลัง. การอัปเดตข้อมูลจริงขึ้นกับ Supabase Auth, RLS และ RPC เดิม. โหมด DEMO ไม่บันทึกข้อมูลขึ้น Supabase. หากเห็นหน้าเดิม ให้เปิดเว็บอีกครั้ง/รีเฟรชแคช PWA หลังอัปโหลด `app.js`, `v7-ui.css`, และ `sw.js` แล้ว
